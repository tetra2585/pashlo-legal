PASHLO 利用規約

制定日：2026年10月31日

この利用規約（以下「本規約」）は、友永景介（以下「運営者」）が提供するアプリ「PASHLO」（以下「本アプリ」）の利用条件を定めるものです。本アプリを利用した時点で、本規約に同意したものとみなします。

第1条（適用）

  1. 本規約は、本アプリの利用に関わる、利用者と運営者の間のすべての関係に適用されます。
  2. プライバシーポリシーおよびアプリ内やサポートページで示すルールは、本規約の一部を構成します。
  3. 本アプリを App Store から入手した利用者には、Apple の定める条件もあわせて適用されます。本規約とそれが食い違う場合、運営者と利用者の間では本規約が優先します。ただし、Apple との関係については Apple の条件が優先します。
  4. 未成年の方は、保護者の同意を得たうえで本アプリを利用してください。

第2条（本アプリの内容）

本アプリは、アプリが声で合図を出し、合図の後に写真を撮影して、撮影前後の動画と組み合わせた作品を作るアプリです。撮影・編集・保存は利用者の端末の中で行われ、運営者は作品を受け取りません。

第3条（Pro）

  1. 本アプリには、無料で使える機能と、有料の機能（以下「Pro」）があります。Pro の内容と価格は、購入画面に表示するとおりとします。
  2. Pro には、App Store のアプリ内課金による次の購入方法があります。
    • 月額プラン：自動更新サブスクリプションです。初めて購入する方には、購入画面に表示する期間の無料体験が付く場合があります。無料体験の終了後、または購入日から1か月ごとに自動で更新され、料金が請求されます。更新日の24時間前までに解約しない限り、自動で更新されます。解約は、端末の「設定」のサブスクリプション管理から行えます。無料体験の期間中に解約すれば、料金はかかりません。
    • 買い切り：一度の支払いで、Pro を続けて利用できます。
  3. 料金、支払い、更新、解約、返金は、Apple の定める方法によります。運営者は、支払いを直接受け付けたり、返金を行ったりできません。
  4. 購入の復元は、購入した App Store のアカウントで行えます。iPhone と Android の間で購入は引き継げません。
  5. Pro が終了すると、Pro でのみ使える機能は使えなくなります。それまでに作った作品は消えません。
  6. 季節やテーマの演出などを、Pro の利用者に追加で提供することがあります。将来のすべての機能の無償提供を約束するものではありません。
  7. 本アプリ内で配る「Pro 演出のチケット」は、1枚で、Pro の演出を使った作品を1つ保存できるものです。換金・譲渡はできません。配布の条件は予告なく変更することがあります。

第4条（作品の権利と取り扱い）

  1. 利用者が本アプリで撮影・作成した写真・動画・作品・マイボイスの権利は、利用者または正当な権利者に帰属します。
  2. 作品は利用者の端末の中に保存されます。本アプリの削除、端末の故障・紛失などで作品が失われても、運営者は復元できません。大切な作品は、写真ライブラリへの保存や作品パッケージの書き出しで保存してください。

第5条（同梱の音声・音楽）

本アプリに同梱した合図の音声・BGM・効果音は、本アプリで作った作品の中で、私的な利用および SNS への投稿に使えます。単体での抜き出し・再配布はできません。

第6条（禁止事項）

利用者は、本アプリの利用にあたり、次の行為をしてはいけません。

  1. 他人の肖像権、プライバシー、著作権その他の権利を侵害する撮影・共有
  2. 撮影されることに同意していない人の撮影・公開
  3. 法令または公序良俗に反する目的での利用
  4. 本アプリの解析・改変・再配布（法令で認められる場合を除きます）
  5. その他、運営者が不適切と合理的に判断する行為

第7条（本アプリの変更・終了）

  1. 運営者は、本アプリの内容を変更し、または提供を終了することがあります。
  2. 提供を終了する場合は、相当の期間をおいて、アプリ内またはサポートページでお知らせします。

第8条（免責）

  1. 撮影のタイミング、まばたき・笑顔の判定、演出の結果は、端末や撮影の環境によって異なり、正確さを保証しません。
  2. 運営者は、本アプリが利用者の特定の目的に合うこと、不具合が一切ないこと、作品が失われないことを保証しません。
  3. 運営者は、本アプリの利用によって利用者に生じた損害について、運営者の故意または重大な過失による場合を除き、責任を負いません。
  4. 前項にかかわらず運営者が責任を負う場合（消費者契約法の適用がある場合を含みます）でも、運営者の故意または重大な過失による場合を除き、その範囲は通常生じる直接の損害に限り、その額は、損害が生じた月から遡って12か月の間に利用者が Pro に支払った金額を上限とします。

第9条（規約の変更）

運営者は、必要に応じて本規約を変更することがあります。変更する場合は、変更後の内容と効力が生じる日を、効力が生じる日より前に本ページまたはアプリ内でお知らせします。効力が生じた日以降に本アプリを利用した場合、変更後の規約に同意したものとみなします。
